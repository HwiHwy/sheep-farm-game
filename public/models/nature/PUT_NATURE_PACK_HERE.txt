Optional Quaternius Ultimate Stylized Nature Pack files go here.

Copy the full downloaded `glTF` folder into this directory, preserving any
companion .bin and texture folders. The game looks for these models:

- BirchTree_1.gltf
- BirchTree_3.gltf
- MapleTree_1.gltf
- MapleTree_3.gltf
- Bush.gltf
- Bush_Large.gltf
- Bush_Flowers.gltf
- Bush_Large_Flowers.gltf

Expected path for the main model files: public/models/nature/glTF/*.gltf
If no local assets are present, the game also tries a public online mirror and
falls back to procedural models if those requests fail.
